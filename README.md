# One-Line Laugh-Off

Entry for make.fun competition `u-zkhiel-one-line-laugh-off-714618ae`: exactly one
funny line, a single joke that lands on a cold read, with no setup notes and no
explanation.

The program writes one line to `/output/entry.txt`:

> I hired a hitman to kill my procrastination — six months later, he's still putting it off.

## How to run

```sh
python3 main.py
```

Python 3.13 standard library only, no network at run time. The program asserts
the entry is exactly one line of 1–200 characters before writing it.
